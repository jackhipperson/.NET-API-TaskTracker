# Task Tracker API

This is a simple Task Tracker API built with .Net Web API. 
It allows users to create, read, update, and delete tasks.

The purpose was to put together a simple project to showcase my skills in .Net Web API development.
This project was coded by a human and is not generated by AI, although a big shout out to intellisense!

The API provides the following endpoints:
- `GET /api/tasks`: Retrieve a list of all tasks.
- `POST /api/tasks`: Create a new task.
- `GET /api/tasks/{id}`: Retrieve a specific task by its ID.
- `PUT /api/tasks/{id}`: Update a specific task by its ID.
- `DELETE /api/tasks/{id}`: Delete a specific task by its ID.

## Prereqs

```.NET SDK 10.0.403```

### Install Entity Framework CL tool:

```bash
dotnet tool install --global dotnet-ef
```

### Start from the /TaskTrackerAPI project folder

```bash
cd TaskTrackerAPI
```

```bash
dotnet build
```

### To initialise the database run the following commands:

```bash
dotnet ef database update
```

### Run the API

```bash
dotnet run
```

The Swagger UI is then available on the url below. 
```bash
http://localhost:5073/swagger/index.html
```

### Running tests

You can run the test suite with the following command:

```bash
cd ..
dotnet test
```
